# 미니 레이스 토너먼트

캐릭터들이 자동으로 달리는 횡스크롤 레이싱 게임입니다. 플레이어는 참가자와 규칙을 정하고 결과를 지켜봅니다.
React + Vite로 만들었고, 게임은 하나의 `<canvas>`에 그려집니다.

> 🏁 **바로 실행하기:** https://hyunbae89.github.io/miniRaceGame/

> 📝 **변경 내역:** [CHANGELOG.md](CHANGELOG.md)

> 📄 **캐릭터 설계 문서:** [질주 레이스 캐릭터 설계](https://claude.ai/artifact/55BUnzkWwfNSahTk3Jubfa#95965225-dc4b.m4qxb9cmp14.1578)
> 어린이·성인·어르신·로봇의 재미 요소, 장점과 패널티, 능력치 비교를 정리한 문서입니다. 링크를 누르면 문서의 "번외: 로봇" 항목으로 바로 이동합니다.

> 🧪 **모션 실험실:** [질주 레이스 모션 실험실](https://claude.ai/artifact/JbyvhTxsRp8BqUrEgKfKBC)
> 캐릭터 동작을 다듬는 방법을 단계별로 한 명씩 움직여 비교해 보는 애니메이션 데모입니다. 아래 "캐릭터 동작"은 이 실험실에서 고른 방식을 게임에 옮긴 것입니다.

## 모션 실험실

게임의 원래 캐릭터 그리기 코드(`drawPerson()`)를 옮긴 기준 캐릭터와, 동작을 다듬는 방법을 하나씩 적용한 캐릭터들을 카드로 나란히 보여 줍니다. 카드마다 캐릭터 한 명이 달립니다.

| 카드 | 내용 |
|---|---|
| 0. 지금 게임 | 비교 기준. 팔다리가 직선 한 개라 앞뒤로만 흔들림 |
| 1. 관절 넣기 | 허벅지·정강이, 위팔·아래팔로 나눠 무릎과 팔꿈치가 접힘 |
| 2. 몸 반동·기울기 | 디딘 발에 맞춘 몸 높이, 두 발이 뜰 때 살짝 떠오름, 상체 숙임, 머리 끄덕임 |
| 3. 상태별 전용 동작 | 출발 자세 → 달리기 → 점프·착지 → 밀치기 → 스턴 → 환호를 차례로 재생 |
| 4. 나이별·개인별 걸음 | 어린이·성인·어르신 전환, 개성 랜덤, 나이별 랜덤 이벤트(한눈팔기·전화·허리) |
| 5. 부가 효과 | 머리카락·치마 흔들림, 흙먼지, 속도선 |
| 6. 로봇 | 계단식 걸음, LED 얼굴, 배터리 게이지. 달리기 → 부스터 → 점프·착지 스파크 → 재부팅 → 환호 |

위쪽 공용 설정에서 재생 속도(1×, 0.5×, 0.25×), 보통/질주, 성별을 바꾸거나 일시정지할 수 있습니다.

## 게임 흐름

```
준비(미리보기) → 카운트다운 3·2·1 → 레이스 → 시상식 → (리플레이 · 다른 사람에게 보내기)
```

1. **준비**
   - 왼쪽 **참가 인원** 영역에서 인원을, 오른쪽 **경기 설정** 영역에서 모드·결과산출·맵을 정합니다.
   - 캔버스 오른쪽에 겹쳐 뜨는 **참가자** 창에서 한 명씩 이름, 옷 색, 종류, 성별을 바꿉니다. 창 아래쪽 버튼(휴대폰은 옆으로 밀기)으로 **기본 탭 → 장신구 탭 → 다음 사람 기본 탭** 순서로 넘어가고, 이전은 거꾸로(장신구 → 기본, 기본 → 이전 사람 기본) 갑니다. 왼쪽 출발선은 가려지지 않아 바꾸는 모습을 바로 볼 수 있습니다.
   - 다 정했으면 참가자 창 위쪽(자리 섞기 옆)의 **최종 결정**을 누릅니다. 아직 보지 않은 참가자가 있으면 번호를 알려 주고, **확인하러 가기**(첫 번째 안 본 참가자로 이동)와 **그대로 결정** 중에서 고릅니다. 창이 사라지고 캔버스 오른쪽 아래에 **참가자 수정** 버튼이 생겨, 누르면 결정이 풀리고 창이 다시 뜹니다. 결정 뒤에 인원이나 참가자 정보를 바꿔도 창이 다시 뜹니다.
   - 캔버스에는 트랙과 레인 구분선, 레인 번호가 표시되고, 캐릭터들이 출발선 뒤에 서 있습니다. 레인은 인원수로 트랙 폭을 똑같이 나눈 크기입니다.
   - 참가자 창이 떠 있는 동안 지금 편집 중인 캐릭터만 흰 외곽선과 함께 선명하게 보이고, 나머지 화면은 흐려집니다.
2. **시작**: 경기 설정 아래의 큰 **경기 시작** 버튼이나 캔버스 위의 **시작** 버튼을 누릅니다. 최종 결정 전에는 자물쇠 표시가 붙고, 누르면 "참가자를 먼저 확정해 주세요" 안내 창이 뜹니다(**최종 결정으로 이동**을 누르면 그 버튼으로 이동). 시작하면 설정 화면이 사라지고 레이스 화면만 남으며, 3초 카운트다운 뒤 출발합니다.
3. **레이스**: 모든 캐릭터가 결승선(트랙 길이 6500)을 통과하면 끝납니다.
   - 경기 중(카운트다운 포함)에는 **■ 경기 중단** 버튼이 있습니다. 누르면 경기가 잠시 멈추고 세 가지를 고를 수 있습니다.
     - **참가자 수정으로 돌아가기**: 인원·참가자 정보는 그대로 두고 최종 결정 전 상태로
     - **완전 초기화**: 인원 4명, 이름 새로 뽑기, 모드·결과산출·맵·자리까지 처음 상태로
     - **취소하고 경기 계속**: 멈춘 자리에서 이어서 진행
4. **시상식**
   - 1~3위가 시상대에 오르고, 꼴찌는 옆에서 웁니다.
   - 결과산출 대상에게 컬러 조명이 켜집니다(아래 '결과산출' 참고).
5. **이후**
   - **다시 시작**: 같은 설정으로 새 레이스를 합니다.
   - **새로 하기**: 같은 참가자(이름·종류·장신구 그대로)로 준비 화면에 돌아가 참가자 창을 첫 사람부터 다시 띄웁니다.

## 준비 화면 설정

설정은 화면 위쪽에 세 영역으로 나뉩니다: 왼쪽 **참가 인원**, 오른쪽 **경기 설정**(모드·결과산출·맵 + 경기 시작), 캔버스 위 **참가자** 창(한 명씩 + 최종 결정). 시작 전에는 새로 하기·리플레이 같은 레이스용 버튼은 보이지 않습니다.

| 항목 | 설명 |
|---|---|
| 참가 인원 | 2~20명(−/+ 버튼). 8명이 넘으면 1명당 트랙 폭이 12px씩 넓어지고, 캔버스 높이도 같이 커집니다. |
| 모드 | **일반** / **아이템전**(?박스에서 아이템을 얻음) 중 하나를 버튼으로 고릅니다. |
| 결과산출 | **1등 원함** / **꼴등 원함**. 시상식에서 조명을 받을 순위를 정합니다. |
| 🔀 자리 섞기(참가자 영역 오른쪽 위) | 출발 레인 순서를 무작위로 섞습니다. 출발선은 모두 같고 위아래 위치만 바뀝니다. **원래 자리** 버튼으로 되돌릴 수 있습니다. |
| 맵 | 장소(**서울 도심** / **전통 마을**)와 시간대(**낮** / **밤**)를 각각 고릅니다. |
| 랜덤 이벤트 | **켜기** / **끄기**. 켜면 레이스 중 돌발 상황이 생깁니다(아래 '랜덤 이벤트'). 끄면 예전과 똑같은 레이스입니다. |
| 장애물 | **있음** / **없음**. 없음이면 허들·물웅덩이·진흙·스프링 발판 없이 달립니다. |
| 참가자 창 | 번호/전체 인원과 출발 레인, 옷 색, 이름(최대 6자), 종류(어린이/성인/어르신/로봇), 성별(남/여). 캔버스 오른쪽 80%에 겹쳐 한 명씩 보여 주고 아래쪽 버튼으로 기본 → 장신구 → 다음 사람 순서로 넘깁니다. PC에서는 이름 옆에 남/여, 아래에 종류(2×2), 오른쪽에 고른 종류의 한 줄 설명이 나오고(자세한 동작은 이후 가이드 페이지에서), 휴대폰에서는 종류·성별이 이름 옆 선택 상자로 바뀝니다. **장신구** 탭은 왼쪽에 장신구 줄(이름 · 종류 버튼), 오른쪽 끝에 같이 쓰는 색 칸이 있습니다. 장신구를 누르면 강조되고, 색 칸에서 그 장신구의 색을 고릅니다(무지개 점은 다른 색). 사람은 가방·목도리·모자(캡모자/비니/고글 모자)·신발(운동화/장화)을 고르고, 어르신은 지팡이(나무/우산/황금)를 고릅니다. 로봇은 LED 눈 색(코어 탱크 액체도 같은 색), 안테나(기본/스프링/위성 접시), 경고 띠, 등 장착물(제트팩/코어 탱크), 발(발가락/역관절)을 바꿉니다. 처음에는 가방·목도리만 캐릭터마다 약 40% 확률로 착용합니다. 참가자 창에서 그 사람으로 넘어오거나 이름·장신구를 바꾸면, 출발선의 캐릭터가 나이대에 맞는 말풍선으로 한마디 하며 짧게 움직입니다(긴장·자신감·일상·이름·장신구 반응, 게임 난수를 쓰지 않아 결과에 영향 없음). 장신구는 그림에만 쓰여 레이스 결과에는 영향이 없습니다. 로봇을 고르면 성별 칸이 사라지고, 이름 앞에 `메카 `가 붙습니다(예: `메카 레오`). 다시 사람으로 바꾸면 성별 칸이 돌아오고 `메카`가 빠집니다. |

- 기본 이름은 남녀 각 20개 목록에서 성별에 맞춰 겹치지 않게 랜덤으로 정해집니다.
- 옷 색은 20가지가 미리 정해져 있습니다.

## 레이스 규칙

### 속도
- 캐릭터마다 기본 속도가 조금씩 다릅니다.
- 0.6~1.8초마다 속도 배율이 랜덤으로 바뀝니다. 바뀌는 경우는 세 가지입니다.
  - 질주: 1.3~1.7배
  - 지침: 0.5~0.75배
  - 보통: 0.95~1.15배
- 결승선 1000 앞부터는 질주가 나올 확률이 높아집니다.
- 선두와 거리가 멀수록 최대 +28%까지 속도 보정을 받습니다. 선두는 약간 느려지는 보정을 받습니다. 그래서 순위가 계속 뒤바뀝니다.
- 캐릭터 옆의 ▲는 질주 중, ▼는 지친 상태를 뜻합니다.

### 장애물
허들과 물웅덩이가 450~800 간격으로 무작위 배치되고, 그 사이 넓은 틈에 진흙 구역이 생깁니다. 트랙 중반부터는 스프링 발판이 놓입니다. 화면 위쪽 지도에도 모두 표시됩니다.

| 장애물 | 피하는 법 | 걸리면 |
|---|---|---|
| 허들 | 점프 | 앞으로 고꾸라졌다가 1.5초 뒤 일어남("꽈당!"). 허들은 레인마다 한 칸씩 사선으로 늘어서 있고, 걸린 칸은 앞으로 쓰러져서 그 레인은 다음 사람부터 그냥 통과합니다(로봇이 버티고 지나가도 쓰러짐) |
| 물웅덩이 | 점프 | 2.2초 스턴("첨벙!"). 세 번째 장애물부터 약 17% 확률로 나옵니다. |
| 진흙 | 못 피함(제트팩만 무시) | 지나는 동안 속도 0.55배("진흙!"). 장애물 사이가 620 이상 벌어진 곳에 최대 3곳 |
| 스프링 발판 | 위아래 위치 운 | 트랙 40% 지점부터 결승 250 앞 사이 무작위 위치에 4개(서로 300 이상 떨어짐). 무작위 레인(맨 아래 포함)을 중심으로 트랙 폭의 42%를 사선으로 덮음. 밟으면 0.75초 동안 뒤로 공중제비를 돌며 약 420 뒤로 튕겨 나감("뿅! 뒤로~"). 발판마다 캐릭터당 한 번만 작동 |

- 캐릭터마다 점프 실력이 60~90%로 정해집니다. 허들이나 물웅덩이에 다가가면 이 확률로 점프해서 피할지가 정해집니다.
- 스프링 발판은 점프로 피하지 않습니다. 레이스 중후반 순위를 뒤흔드는 장치입니다.
- 스턴에서 풀린 직후에는 잠깐 무적 상태가 됩니다.

### 랜덤 이벤트
경기 설정에서 켜면, 캐릭터마다 약 60% 확률로 트랙 15~80% 지점 중 한 곳에서 한 번 돌발 상황이 생깁니다. 좋은 일(빨라짐)과 나쁜 일(느려짐·멈춤·뒤로 감)이 반반이고, 공통 이벤트와 자기 종류의 이벤트 중에서 뽑습니다. 주자는 말풍선으로 한마디 하고, 응원 이벤트는 관중석 쪽에 노란 말풍선이 뜹니다. 넘어져 있거나 탈것·점프 중이면 끝날 때까지 미룹니다.

| 대상 | 좋은 일 | 나쁜 일 |
|---|---|---|
| 공통 | 뒷바람(1.35배) · 관중 함성(1.25배) · 물 한 모금(로봇은 배터리, 이후 1.4배) · 관중 하이파이브(1.3배) | 반대로 뛰기(잠깐 뒤로) · 낙엽 돌풍(거의 멈춤) · 혼자 미끄러짐 · 맞바람(0.75배) · 갑자기 깨달음(어린이는 숙제, 로봇은 업데이트) |
| 어린이 | 부모님 응원(1.45배) · 비행기 놀이(1.35배) · 사탕 힘(1.3배) | 나비 쫓기(0.35배) · 아이스크림 발견 · 신발 끈 풀림 |
| 성인 | 전력 질주(1.5배) · 커피 수혈(1.4배) · 운동 앱 알림(1.3배) | 전화 받기(0.65배) · 셀카 타임 · 종아리 쥐 |
| 어르신 | 왕년의 질주(1.55배) · 손주 응원(관중 "할아버지다~!", 1.4배) · 지팡이 높이뛰기(1.7배) | 허리 삐끗 · 지팡이 떨어뜨림 · 안경 찾기 |
| 로봇 | 터보 모드(1.6배) · 자율 주행(1.4배) · 바퀴 모드(1.5배) | 블루스크린 · 문워크(뒤로) · 와이파이 끊김(0.4배) |

- 이벤트 하나는 1.8~2.4초입니다. 배율은 그동안 기본 속도에 곱하는 값이고, 멈추는 이벤트는 그 시간 동안 멈춥니다.
- 리플레이·GIF·MP4에도 같은 이벤트가 그대로 나옵니다.

### 숨은 장면: 개 산책
서울 도심 맵의 아래쪽 인도를 지나가는 개 산책 행인을 레이스 중에 세 번 누르면(휴대폰은 터치) 목줄을 놓치고 강아지가 신나게 달려갑니다. 달아나는 강아지를 누르면 멈춰 서고, 주인이 뛰어와 다시 목줄을 잡습니다. 레이스 결과에는 영향이 없습니다.

### 몸싸움
가까이 붙은 캐릭터끼리 1.3~2.3초 간격으로 몸싸움을 합니다.
- **밀치기**: 상대를 뒤로 밀치고 옆으로 튕겨 냅니다. 상대는 잠깐 느려집니다.
- **잡아당기기**: 앞에 있는 상대를 0.8초 동안 붙잡습니다. 그동안 자신은 앞으로, 상대는 뒤로 끌려갑니다.

### 위아래 이동
캐릭터는 트랙의 위아래(깊이)로 자유롭게 이동합니다. 서로 겹치면 밀려나서 자리를 잡습니다.

### 캐릭터 동작
캐릭터는 `drawPerson()`이 코드로 직접 그립니다. 시뮬레이션 결과에는 영향을 주지 않습니다.
- **관절**: 다리는 허벅지·정강이, 팔은 위팔·아래팔로 나뉘어 무릎과 팔꿈치가 접힙니다. 뒤쪽 팔다리는 한 톤 어둡게 그려 앞뒤가 구분됩니다.
- **반동·기울기**: 디딘 발이 땅에 붙도록 몸 높이를 맞추고, 두 발이 뜨는 순간에는 살짝 떠오릅니다. 상체는 앞으로 숙이고 질주(▲) 중에는 더 숙입니다. 머리는 반 박자 늦게 끄덕입니다.
- **상태별 동작**
  - 카운트다운: 웅크린 출발 자세
  - 점프: 다리를 접고, 착지할 때 몸이 잠깐 찌그러짐
  - 스턴: 비틀거림
  - 밀치기: 팔을 앞으로 뻗음
  - 잡아당기기: 팔을 당김
  - 탈것: 앉은 자세, 또는 핸들을 잡은 자세
  - 1~3위 도착 후: 환호
  - 자세가 바뀔 때는 0.15초 동안 이전 자세에서 자연스럽게 이어집니다.
- **나이·개성**
  - 어린이: 짧고 빠른 걸음
  - 어르신: 작은 보폭, 팔을 덜 흔들고, 지팡이를 짚음
  - 캐릭터마다 보폭, 팔 흔들기, 상체 숙임, 발 빠르기가 조금씩 랜덤으로 다릅니다.
- **부가 효과**: 머리카락과 치마가 몸보다 늦게 따라 흔들립니다. 발을 디딜 때 흙먼지가 일고, 질주 중에는 몸 뒤로 속도선이 지나갑니다.

### 배경(맵)
준비 화면의 **맵**에서 4가지 중 하나를 고릅니다. 먼 배경은 카메라보다 느리게 움직여(시차) 거리감을 줍니다.

| 맵 | 풍경 |
|---|---|
| 서울 도심 | 남산과 N서울타워, 롯데월드타워, 63빌딩이 번갈아 지나가고, 빌딩에는 "치킨", "카페", "PC방" 같은 한글 간판이 붙어 있습니다. 도로는 회색 아스팔트, 인도에는 가로수와 펜스가 있습니다. |
| 전통 마을 | 북한산 같은 바위산 능선 아래로 기와지붕 한옥이 늘어서고, 일정 간격으로 광화문 같은 궁궐 대문이 나옵니다. 도로는 흙길, 인도에는 소나무와 기와 얹은 돌담이 있고 갓을 쓴 시민도 섞여 있습니다. |
| 밤 버전 | 하늘 곳곳에서 폭죽이 터지고(시간으로만 계산해 레이스 결과에 영향 없음), 별과 초승달이 뜨고 창문·간판에 불이 켜집니다. 도심은 가로등, 전통 마을은 청사초롱이 켜지고 도로에 빛이 번집니다. 헬기에는 빨간 경고등이 깜빡이고 조명이 더 밝아집니다. |

- 공통으로 위쪽 인도에는 손을 흔드는 시민들이 있고, 몇몇은 "힘내!", "화이팅!" 같은 피켓을 듭니다. 곳곳에서 두 사람이 "끝까지 달려라!" 같은 현수막의 양 끝 나무 막대를 각자 두 손으로 잡고 들고, 밤 경기에는 모두 빛나는 응원봉을 흔듭니다. 아래쪽 인도에서는 사람들이 강아지와 산책합니다.
- 하늘의 "NEWS" 취재 헬기는 레이스 중에는 카메라가 따라가는 캐릭터 쪽으로 움직이며 조명을 비춥니다. 시작 전에는 캔버스 위 마우스의 좌우 위치를 따라가고, 마우스가 캔버스를 벗어나면 마지막 위치에서 제자리 비행합니다.

### 연출
- **이름표**: 카운트다운 중에는 숨기고, 출발 후 0.5초에 걸쳐 나타납니다. 1위 → 꼴찌 → 카메라가 따라가는 캐릭터 → 나머지 순위순으로 그리면서, 이미 그린 이름표와 겹치는 이름표는 건너뛰고 머리 위에 옷 색 점만 남깁니다. 흩어지면 다시 보입니다(결승 후 "N위" 표시도 같음).
- 1~3위가 결승선을 통과할 때마다 슬로 모션과 "N위 이름" 배너가 나옵니다.
- 화면 오른쪽 위(지도 아래)에 작은 실시간 순위표가 표시됩니다. 6명 이하는 전원, 7명 이상은 1~4위·"⋯ 외 N명"·꼴찌만 보여 주고, 도착한 캐릭터에는 ✓가 붙습니다.

## 로봇

로봇은 스태미나 대신 배터리와 열을 관리하는 캐릭터입니다.

**속도**
- 배터리가 남아 있으면 다른 캐릭터처럼 속도가 랜덤으로 오르내리지 않고 일정한 속도를 유지합니다(크루즈).
- 뒤처진 캐릭터가 따라잡도록 돕는 속도 보정은 똑같이 받습니다.

**배터리**
- 100에서 시작하고 달리는 동안 초당 3.2씩 줄어듭니다.
- 배터리가 0이 되면 급정지하고, 2.2초 동안 충전한 뒤 다시 달립니다. 이때 화면에 `ERROR`, `LOW`가 표시됩니다.

**부스터**
- 배터리가 가득 차면 자동으로 발동합니다. 1.3초 동안 1.75배 속도로 달리고, 배터리를 35 씁니다.
- 출발 직후에 한 번 발동하고, 이후에는 충전으로 다시 가득 찼을 때 발동합니다.

**과열**
- 부스터를 쓰는 동안 열이 오르고, 평소에는 천천히 식습니다.
- 열이 100이 되면 2초 동안 절반 속도로 달립니다.

**무게**
- 밀치기를 맞아도 30%만 밀려납니다.
- 로봇이 밀치는 힘은 1.5배입니다.
- 점프 높이는 사람의 2/3입니다.

**장애물**
- 허들이나 물웅덩이에 걸려도 25% 확률로 버팁니다("끄떡없음!"). 물웅덩이에 빠지면 "합선!"이 납니다.
- 진흙에서는 오작동으로 속도가 0.42배까지 떨어집니다("오작동!").
- 무거워서 스프링 발판에 튕겨 나가는 거리가 사람의 60%입니다.
- 스턴에 걸리면 재부팅 시간이 일반 스턴의 1.5배입니다. LED 화면에 `REBOOT` 진행 바가 찹니다.

**아이템전**
- ?박스를 먹으면 30% 확률로 아이템 대신 배터리가 40 충전됩니다.

**동작과 연출**
- 걸음이 45도 단위로 끊겨 '틱틱' 움직이는 기계식입니다.
- 얼굴이 LED 화면이라 상황에 맞는 픽셀 표정을 보여 줍니다(`^_^`, `>_<`, `ERROR` 등).
- 부스터 중에는 등에서 불꽃이 나오고, 과열과 재부팅 중에는 연기가 납니다.
- 착지할 때 흙먼지 대신 불꽃이 튀고 화면이 흔들립니다.
- 환호할 때는 머리가 360도 돌고 가슴에서 폭죽이 나옵니다.
- 이름표 오른쪽에 배터리 아이콘이 표시됩니다. 충전 중이면 ⚡ 표시가 나오고, 과열에 가까우면 테두리가 빨갛게 바뀝니다.

**밸런스**: 크루즈 속도는 일반 모드 1.16배, 아이템전 1.06배입니다. 시뮬레이션에서 로봇과 사람의 평균 순위가 비슷해지도록 맞춘 값입니다.

## 시상식과 결과산출

- 1위는 금색, 2위는 은색, 3위는 동색 시상대에 오릅니다. 각 시상대에는 등수 아래에 캐릭터 이름이 적힙니다.
- 꼴찌는 왼쪽에서 걸어 들어와 바닥에 서서 웁니다. 옆에 꽂힌 `꼴등` 화살표 표지판이 꼴찌를 가리킵니다.
  - 꼴찌가 2위나 3위인 경우(참가자 2~3명)에는 그 순위의 시상대를 비우고 꼴찌 자리에 섭니다.
  - 꼴찌 머리 위에는 이름표와 "흑흑…" 말풍선이 나옵니다.
  - 꼴찌가 로봇이면 눈물 웅덩이가 생기지 않고, 말풍선이 "삐빅… 패배 감지"로 바뀝니다.
- **1등 소감 말풍선**
  - 1위가 결승선을 통과하면 머리 위에 3.5초 동안 말풍선이 뜹니다.
  - 시상식에서 1위가 시상대에 착지한 뒤에도 같은 말풍선이 나옵니다.
  - 멘트는 캐릭터 종류별로 4개 중 하나가 랜덤으로 나옵니다.

  | 종류 | 멘트 |
  |---|---|
  | 어린이 | 야호! 내가 1등이다! · 엄마, 나 봤어?! · 한 번 더 할래! · 사탕 사 주세요! |
  | 성인 | 출근길보다 쉽네요 · 역시 꾸준함이 답이죠 · 오늘 회식은 제가 쏩니다! · 지각은 면했다! |
  | 어르신 | 허허, 아직 안 죽었어 · 젊은이들, 분발하게 · 이 동네 오래 살았지 · 다 지팡이 덕분이야 |
  | 로봇 | 목표 달성. 1위 확인. · 삐빅! 승리 프로토콜 실행 · 배터리 잔량 충분 · 인간 대비 성능 우위 |
- 결과산출로 고른 순위의 캐릭터에게 컬러 조명이 켜집니다.
  - **1등 원함**: 1위
  - **꼴등 원함**: 꼴찌
- 조명이 켜지는 동안 나머지 화면은 흑백으로 바뀌고, 조명 원 안은 약 1.25배 확대된 컬러로 보입니다.
- 조명은 0.6초 동안 켜지고, 4.5초 동안 유지된 뒤, 0.6초 동안 꺼지면서 전체 컬러 화면으로 돌아옵니다.
- 캔버스 아래 결과 목록에 최종 순위와 완주 시간이 나옵니다. 맨 위에는 `결과 산출 · 1등: 이름` 문구가 표시됩니다.
  - 1등 원함: 1·2·3위 줄이 각각 옅은 금·은·동색으로 강조됩니다.
  - 꼴등 원함: 꼴찌 줄만 옅은 하늘색으로 강조됩니다.

## 카메라 · 리플레이 · 저장

- **카메라**
  - 기본적으로 아직 도착하지 않은 1위를 따라갑니다. 1위가 결승선을 통과하면 다음 순위 캐릭터로 넘어가고, 모두 도착하면 마지막 도착자에 머뭅니다.
  - 레이스 중 캔버스를 누르면(휴대폰은 손가락으로 터치) 누른 지점이 화면 가운데로 오고, 누른 채 좌우로 끌면 화면을 잡아끌듯 움직입니다.
  - 화면 위쪽 지도를 누르거나 끌면 그 비율 위치로 이동합니다.
  - 손을 떼면 바로 자동 카메라로 돌아가 다시 1위를 따라갑니다. 휴대폰에서 위아래로 밀면 페이지가 스크롤됩니다.
- **리플레이**: 카운트다운(3·2·1)부터 레이스 끝까지 매 프레임을 기록해 두었다가 시상식 이후에 다시 재생합니다.
- **다른 사람에게 보내기**: 리플레이 중에 **📤 다른 사람에게 보내기**를 누르고 **움짤(GIF)**(가벼움) 또는 **영상(MP4)**(선명)을 고릅니다. 다 만들어지면 **📤 보내기**를 눌러 기기의 공유 창(카카오톡·메시지 등)으로 보내고, 공유 창을 지원하지 않는 브라우저(예: PC Firefox)에서는 파일로 저장합니다. **⬇ 저장**으로 파일만 받을 수도 있습니다.
- **저장 범위(MP4·GIF 공통)**: 카운트다운 3·2·1 → 레이스 → 시상식까지 담고, 결과산출 조명이 꺼지고 2초 뒤에 끝납니다(1등 원함이면 시상식 시작 후 약 11.1초, 꼴등 원함이면 약 10.1초).
- **움짤(GIF)**: 위 범위를 0.1초 간격, 폭 400px GIF로 만듭니다. 외부 라이브러리 없이 직접 인코딩합니다.
- **영상(MP4)**
  - 위 범위를 화면 그대로 녹화합니다. 레이스 리플레이가 끝나도 녹화를 멈추지 않고 시상식으로 이어 갑니다.
  - 브라우저가 MP4 녹화를 지원하지 않으면 WebM으로 만듭니다.
- 파일이 준비되면 **📤 보내기**와 **⬇ 저장** 버튼이 나타납니다. 파일 이름에는 만든 시각이 붙습니다(예: `race-replay_2026-11-25_18-21-51.mp4`).

## 실행

```bash
npm install
npm run dev      # 개발 서버
npm run build    # dist/ 에 정적 파일 생성
npm run preview  # 빌드 결과 미리보기
npm run check    # 엔진 자동 점검(아래 참고)
```

**자동 점검(`npm run check`)**
- 브라우저 없이 Node로 게임 엔진을 돌립니다. 난수와 시간을 고정한 채 미리보기, 일반전, 아이템전, 맵 4종 시나리오를 시상식과 리플레이까지 진행합니다.
- 레이스가 끝나지 않거나 그리기에 NaN이 들어가면 실패합니다.
- 캔버스에 내린 모든 그리기 명령을 해시로 기록해 `scripts/check-baseline.json`의 기준과 비교합니다. 리팩터링 전후에 결과가 같으면 화면이 한 획도 달라지지 않았다는 뜻입니다.
- 레이스 시나리오는 그리기와 따로 리플레이 기록(매 프레임 위치·순위·장애물)도 `sim` 해시로 비교합니다. 기준과 다르면 "그림만 다름"인지 "레이스 결과·동작도 다름"인지 알려 줍니다.
- 그림이나 동작을 일부러 바꿨다면 `npm run check -- --update`로 기준을 갱신합니다.
- 점검 전에 모든 게임 모듈에서 정의되지 않은 이름(빠진 import 등)이 없는지도 확인합니다. 빌드로는 잡히지 않는 실수입니다.
- `npm run check -- --balance`는 로봇과 사람의 평균 순위를 모드별 40판으로 측정합니다.

- `vite.config.js`의 `base`가 `/miniRaceGame/`로 되어 있습니다. 그래서 개발 서버 주소는 `http://localhost:5173/miniRaceGame/`입니다.
- `dist/index.html`을 파일로 직접 열면 브라우저가 모듈 스크립트를 막습니다. 반드시 서버나 호스팅을 통해 여세요.

**상태 관리**: 게임 한 판의 가변 상태(캐릭터, 카메라, 장애물, 리플레이 프레임 등)는 모두 `state.js`의 `G` 객체 하나에 있고, 각 모듈은 `G.racers`, `G.camX`처럼 읽고 씁니다. 고정 값은 `constants.js`에서 가져옵니다. 새 기능은 해당 영역 파일만 고치면 되도록 나눠 두었습니다(예: 새 맵은 `render/background.js`, 새 장애물은 `sim/race.js`와 `render/race.js`).

엔진은 React와 분리되어 있습니다.
- `createGame(canvas, { onChange })`가 돌려주는 메서드로 게임을 조작합니다.
- 상태가 바뀔 때마다 `onChange` 콜백으로 UI 상태 객체가 전달됩니다.

| 메서드 | 역할 |
|---|---|
| `setN(n)` | 참가 인원 설정(2~20). 준비 상태로 돌아갑니다. |
| `setMode(m)` | `'normal'` / `'item'` |
| `setWant(w)` | 결과산출 순위: `'first'` / `'last'` |
| `setCfg(i, patch)` | i번 캐릭터의 `name`, `color`, `gender`, `age` 변경 |
| `shuffleLanes()` / `resetLanes()` | 출발 레인 섞기 / 원래대로 |
| `setMap(m)` | 맵: `'city-day'`, `'city-night'`, `'trad-day'`, `'trad-night'` |
| `setHover(i)` | 미리보기에서 i번 캐릭터 강조(`-1`이면 해제) |
| `start()` / `reset()` | 레이스 시작(또는 다시 시작) / 준비 화면으로 |
| `toggleReplay()` | 리플레이 시작/종료 |
| `exportGif()` / `exportVideo()` / `shareReady()` / `saveReady()` | GIF·영상 만들기(리플레이 중이면 끝내고 시작) / 만든 파일 보내기 / 저장 |
| `follow()` | 자동 카메라로 복귀 |
| `setPaused(b)` | 경기 일시정지/재개 |
| `stop()` | 경기를 멈추고 준비 화면으로(참가자 정보 유지) |
| `resetAll()` | 완전 초기화(참가자·인원·모드·결과산출·맵·자리) |
| `destroy()` | 애니메이션 루프와 이벤트 정리 |
