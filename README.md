# 질주 레이스

캐릭터들이 자동으로 달리는 횡스크롤 레이싱 게임입니다. 플레이어는 참가자와 규칙을 정하고 결과를 지켜봅니다.
React + Vite로 만들었고, 게임은 하나의 `<canvas>`에 그려집니다.

## 게임 흐름

```
준비(미리보기) → 카운트다운 3·2·1 → 레이스 → 시상식 → (리플레이 · GIF/MP4 저장)
```

1. **준비**
   - 상단 바에서 참가 인원, 모드, 결과산출 순위를 정합니다.
   - 아래 카드에서 캐릭터마다 이름, 옷 색, 성별, 나이를 바꿀 수 있습니다.
   - 캔버스에는 트랙 라인, 출발선, 캐릭터만 선명하게 보이고 나머지 배경은 흐리게 처리됩니다.
2. **시작**: 커스터마이징 창이 사라지고 레이스 화면만 남습니다. 3초 카운트다운 뒤 출발합니다.
3. **레이스**: 모든 캐릭터가 결승선(트랙 길이 6500)을 통과하면 끝납니다.
4. **시상식**
   - 1~3위가 시상대에 오르고, 꼴찌는 옆에서 웁니다.
   - 결과산출 대상에게 컬러 조명이 켜집니다(아래 '결과산출' 참고).
5. **이후**
   - **다시 시작**: 같은 설정으로 새 레이스를 합니다.
   - **새로 하기**: 준비 화면으로 돌아갑니다.

## 준비 화면 설정

| 항목 | 설명 |
|---|---|
| 참가 인원 | 2~20명. 8명이 넘으면 1명당 트랙 폭이 12px씩 넓어지고, 캔버스 높이도 같이 커집니다. |
| 모드 | **일반**, 또는 ?박스에서 아이템을 얻는 **아이템전** |
| 결과산출 | **1등 원함** / **꼴등 원함**. 시상식에서 조명을 받을 순위를 정합니다. |
| 🔀 자리 섞기 | 출발 레인 순서를 무작위로 섞습니다. 출발선은 모두 같고 위아래 위치만 바뀝니다. **원래 자리** 버튼으로 되돌릴 수 있습니다. |
| 캐릭터 카드 | 출발 레인 번호, 옷 색, 이름(최대 6자), 성별(남/여), 나이(어린이/성인/어르신) |

- 기본 이름은 남녀 각 20개 목록에서 성별에 맞춰 겹치지 않게 랜덤으로 정해집니다.
- 옷 색은 20가지가 미리 정해져 있습니다.

## 레이스 규칙

### 속도
- 캐릭터마다 기본 속도가 조금씩 다릅니다.
- 0.6~1.8초마다 속도 배율이 랜덤으로 바뀝니다. 바뀌는 경우는 세 가지입니다.
  - 질주: 1.3~1.7배
  - 지침: 0.5~0.75배
  - 보통: 0.95~1.15배
- 결승선 1000 앞부터는 질주가 나올 확률이 높아집니다.
- 선두와 거리가 멀수록 최대 +28%까지 속도 보정을 받습니다. 선두는 약간 느려지는 보정을 받습니다. 그래서 순위가 계속 뒤바뀝니다.
- 캐릭터 옆의 ▲는 질주 중, ▼는 지친 상태를 뜻합니다.

### 함정
트랙에는 함정이 450~800 간격으로 무작위 배치됩니다.

| 함정 | 걸리면 |
|---|---|
| 가시 | 1.6초 스턴 |
| 구덩이 | 2.4초 스턴 ("풍덩!"). 세 번째 함정부터 약 17% 확률로 나옵니다. |

- 캐릭터마다 점프 실력이 60~90%로 정해집니다. 함정에 다가가면 이 확률로 점프해서 피할지가 정해집니다.
- 스턴에서 풀린 직후에는 잠깐 무적 상태가 됩니다.

### 몸싸움
가까이 붙은 캐릭터끼리 1.3~2.3초 간격으로 몸싸움을 합니다.
- **밀치기**: 상대를 뒤로 밀치고 옆으로 튕겨 냅니다. 상대는 잠깐 느려집니다.
- **잡아당기기**: 앞에 있는 상대를 0.8초 동안 붙잡습니다. 그동안 자신은 앞으로, 상대는 뒤로 끌려갑니다.

### 위아래 이동
캐릭터는 트랙의 위아래(깊이)로 자유롭게 이동합니다. 서로 겹치면 밀려나서 자리를 잡습니다.

### 연출
- 1~3위가 결승선을 통과할 때마다 슬로 모션과 "N위 이름" 배너가 나옵니다.
- 화면 오른쪽 위에 실시간 순위가 표시됩니다. 10명이 넘으면 2열로 나뉩니다.

## 아이템전

트랙에 ?박스가 일정 간격으로 놓입니다. 박스를 먹으면 0.5~1.2초 뒤 아이템이 자동으로 사용됩니다. 먹은 박스는 6초 뒤 다시 생깁니다.

| 종류 | 아이템 | 효과 |
|---|---|---|
| 탈것 | 🚀 제트팩 | 2.0배 속도, 2.2초. 공중을 날아서 함정을 무시합니다. |
| | 🏍️ 오토바이 | 1.75배, 3.4초 |
| | 🛴 전동 킥보드 | 1.65배, 3초 |
| | 🏎️ 카트 | 1.55배, 3초 |
| | 🚲 자전거 | 1.35배, 4초 |
| | 🛴 킥보드 | 1.3배, 4초 |
| | ♿ 휠체어 | 1.2배, 5초. 타는 동안 밀치기를 당하지 않습니다("끄떡없음!"). |
| 공격 | 🍌 바나나 | 뒤에 바나나를 떨굽니다. 밟은 캐릭터는 1.2초 스턴됩니다. |
| | 🔫 스턴건 | 앞쪽 700 안에서 가장 가까운 상대를 1.8초 감전시킵니다. 대상이 없으면 잠시 들고 있다가 다시 시도합니다. |
| 이동 | 🌀 포탈건 | 앞으로 520만큼 순간이동합니다. |

## 시상식과 결과산출

- 1위는 금색, 2위는 은색, 3위는 동색 시상대에 오릅니다. 꼴찌는 왼쪽 언덕 아래에서 웁니다.
- 결과산출로 고른 순위의 캐릭터에게 컬러 조명이 켜집니다.
  - **1등 원함**: 1위
  - **꼴등 원함**: 꼴찌
- 조명이 켜지는 동안 나머지 화면은 흑백으로 바뀌고, 조명 원 안은 약 1.25배 확대된 컬러로 보입니다.
- 조명은 0.6초 동안 켜지고, 4.5초 동안 유지된 뒤, 0.6초 동안 꺼지면서 전체 컬러 화면으로 돌아옵니다.
- 화면 아래와 결과 목록에 `결과 산출 · 1등: 이름` 문구가 표시됩니다.
- 캔버스 아래에는 최종 순위와 완주 시간이 나옵니다.

## 카메라 · 리플레이 · 저장

- **카메라**
  - 기본적으로 선두를 따라갑니다.
  - 레이스 중 화면 위쪽 지도를 클릭하거나 드래그하면 원하는 구간을 볼 수 있습니다.
  - **자동 카메라**를 누르면 다시 선두를 따라갑니다.
- **리플레이**: 레이스의 매 프레임을 기록해 두었다가 시상식 이후에 다시 재생합니다.
- **GIF 만들기**: 리플레이를 폭 400px GIF로 만듭니다. 외부 라이브러리 없이 직접 인코딩합니다.
- **MP4 만들기**
  - 리플레이를 녹화합니다.
  - 브라우저가 MP4 녹화를 지원하지 않으면 WebM으로 만듭니다.
- 파일이 준비되면 **⬇ 파일명 저장** 버튼이 나타납니다.

## 실행

```bash
npm install
npm run dev      # 개발 서버
npm run build    # dist/ 에 정적 파일 생성
npm run preview  # 빌드 결과 미리보기
```

- `vite.config.js`의 `base`가 `/miniRaceGame/`로 되어 있습니다. 그래서 개발 서버 주소는 `http://localhost:5173/miniRaceGame/`입니다.
- `dist/index.html`을 파일로 직접 열면 브라우저가 모듈 스크립트를 막습니다. 반드시 서버나 호스팅을 통해 여세요.

## 구조

```
src/
  App.jsx          UI (상단 컨트롤, 캐릭터 카드, 최종 순위)
  App.css          스타일 (라이트/다크 테마)
  main.jsx         진입점
  game/engine.js   캔버스 게임 엔진
```

엔진은 React와 분리되어 있습니다.
- `createGame(canvas, { onChange })`가 돌려주는 메서드로 게임을 조작합니다.
- 상태가 바뀔 때마다 `onChange` 콜백으로 UI 상태 객체가 전달됩니다.

| 메서드 | 역할 |
|---|---|
| `setN(n)` | 참가 인원 설정(2~20). 준비 상태로 돌아갑니다. |
| `setMode(m)` | `'normal'` / `'item'` |
| `setWant(w)` | 결과산출 순위: `'first'` / `'last'` |
| `setCfg(i, patch)` | i번 캐릭터의 `name`, `color`, `gender`, `age` 변경 |
| `shuffleLanes()` / `resetLanes()` | 출발 레인 섞기 / 원래대로 |
| `start()` / `reset()` | 레이스 시작(또는 다시 시작) / 준비 화면으로 |
| `toggleReplay()` | 리플레이 시작/종료 |
| `exportGif()` / `exportVideo()` / `saveReady()` | GIF·영상 만들기 / 만든 파일 저장 |
| `follow()` | 자동 카메라로 복귀 |
| `destroy()` | 애니메이션 루프와 이벤트 정리 |
